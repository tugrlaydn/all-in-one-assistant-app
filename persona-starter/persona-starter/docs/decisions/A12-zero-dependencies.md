# A12 — Zero dependencies to start

**Why this one.** In a project meant to live for years, every dependency is a future breaking update, a licence to check, and a build-time cost. Nothing in P0–P9 needs one. Adding one is Tier B with a decision file — cheap when justified, never by default.
