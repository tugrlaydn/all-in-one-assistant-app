## In plain language
Persona now has a real skeleton. There is an app project with one window showing a placeholder
calendar: seven days side by side around today, with today's column wide in the middle. There is also a

## Technical detail
- **Commits:** `chore` flatten → `chore` .claude/ + .gitignore + LICENSE → `feat(vault)` VaultKit/ULID →
  `feat(design)` DesignKit → `feat(app)` app shell + Makefile + CI → this report.
- **`.claude/`:** `settings.json` (acceptEdits; deny Read/Edit/Write of `~/Library/Mobile Documents`,
  `~/Documents`, `~/Desktop`, `~/Downloads`, Edit/Write of `~/Library/Preferences` and `docs/SPEC.md`;
  SessionStart + PreToolUse hooks). `hooks/guard-paths.py` resolves symlinks for paths that don't
  exist yet; checks redirections, rm/mv/cp/tee/mkdir/touch/`sed -i` targets and `defaults write`.
  `read-only-bash.py` (reviewer) and `limit-writes.py <prefixes>` (vault-tester, renderer) are wired
  through subagent frontmatter `hooks:`. Skills `/report`, `/propose` inject date, status, commits and
  next id with `` !`cmd` ``. Rules `vaultkit.md`, `ui.md` use `paths:` frontmatter.
  Hook test suites: guard 29/29, subagent hooks 17/17 (run from a scratch directory, not committed).
- **Lesson (recorded, not a new process):** when enabling a hook, write the script *before* the
  settings entry that calls it. Claude Code applies settings changes mid-session, and a missing
  script makes `python3` exit 2, which counts as "block".
- **VaultKit:** `ULID`, stored as two `UInt64`s; Crockford base32 encode/decode by 5-bit shifts across the
  128-bit pair; first character ≤ 7 (130-bit overflow check); I/L/O aliases; `Comparable` matches string
  order; `Codable` as string; the millisecond timestamp is rounded to nearest (flooring turned `.385`
  into 384). Tests: Swift Testing, 8 tests (1000 random round-trips, spec vector
  `01ARYZ6S41TSV4RRFFQ69G5FAV`) — **green on Swift 6.2 / Linux** (Docker `swift:6.2-noble`).
- **DesignKit:** `Palette` (system-colour placeholders, Tier A until P2), `Typography` (display/title/
  body/meta + tabular numerals), `Spacing` (4-pt grid), `Motion` (quick 0.25 s / settle 0.45 s springs;
  Reduce Motion → 0.2 s crossfade), `HorizonLayout.columnWidths` (focus share 0.42, the others weighted
  `1/(1 + 0.25·(d−1))`, exact fill). HorizonLayout 5/5 green on Linux; `MotionTests` need macOS.
- **App:** `Window` + `MenuBarExtra` (`sun.horizon`); `HorizonPlaceholderView` with 7 columns and
  hairline separators; `LaunchOptions` (`--vault <p>` / `--vault=<p>`, last wins, debug only; turns
  off notifications and launch-at-login); `BuildFlavor.checkSeparation()` preconditions at launch.
  App tests: 7 (Swift Testing, hosted). The Foundation-only ones pass on Linux; running them on Linux caught
  a real bug (`URL(fileURLWithPath:relativeTo:)` with a base that has no trailing slash).
- **Build:** `project.yml` (macOS 26, Swift 6, sandbox + user-selected RW + app-scope bookmarks,
  ad-hoc signing), `Makefile` (`gen build test run format`; `vault-dump`/`stress-vault`/`clean-stress`/
  `dist` exit with the phase that brings them), `.swiftformat`.
- **CI:** `.github/workflows/ci.yml` on `macos-26`: `brew install xcodegen`, `make gen build test`.
  Result for `fade5a8`: still running when this report was written — [run 1](https://github.com/tugrlaydn/all-in-one-assistant-app/actions/runs/36432268780). The next commit records the outcome.
- **Not done / not verified:** the app has not been run or looked at; `/doctor` and the `~/Documents`
  block have to be confirmed in Claude Code on your Mac (the guard was verified here with a simulated
  home directory, and live against a write to `~`); Figma file (seat); `python3` resolves on the Mac
  (it ships with the Xcode command-line tools).
- **Risks:** `Motion` equality tests assume `Animation` equality compares spring parameters; the
