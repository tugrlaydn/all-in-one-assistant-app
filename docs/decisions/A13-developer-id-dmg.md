# A13 — Developer ID + notarised dmg; not the App Store

*Alternatives:* Mac App Store · unsigned builds run from Xcode forever.
**Why this one.** A single-user app gains nothing from App Store review cycles and receipt handling. Notarisation keeps Gatekeeper quiet and makes a clean install on a second Mac a drag-and-drop. It needs the owner's Developer membership at P9 only. Running from Xcode forever is fine until the day the owner wants it on a second Mac.
**Reversal cost.** Low — the App Store can be added later.
