# P6 — Habits (3 sessions)

Status: not started · Read also: `docs/plan/working-agreements.md` (§8.1 loop, §8.3 code rules, §8.6 test data) and any decision file this phase names.

- [ ] Habit management: the five fixed categories, create/archive habits, budgets in `Categories.md` editable from the app.
- [ ] Week view (`⌘4`): per category — planned hobby, budget bar (logged ÷ budget), the log table; a "Plan this week" sheet.
- [ ] Logging from four places: quick input, the chip on the Horizon, the week view, the menu-bar popover.
- [ ] Pace engine (VaultKit): expected-vs-logged minutes per category for the current week; "behind pace" is a pure, tested function.
- [ ] Nudges: `UNUserNotificationCenter`, fired at `nudge_times` only for categories behind pace; actions **Log 15 · Log 30 · Log default · Log…** (text input using the `h` grammar) write the week file even when the app is only in the background; a Monday-morning "plan your week" nudge.
- [ ] Habit chips on the Horizon for logged days; a weekly summary section in the report format.
- [ ] Category glyphs: five small objects rendered in Blender (light and dark sets, PNG) — proposed from renders, ratified by the owner, then used in the week view and chips.

Acceptance: a whole week can be planned, logged, and reviewed using only notifications and quick input.
